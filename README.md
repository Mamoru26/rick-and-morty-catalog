# Rick and Morty — каталог персонажей

Тестовое задание: приложение на Flutter для просмотра и поиска персонажей через [Rick and Morty API](https://rickandmortyapi.com/documentation).

## Что умеет

- список персонажей с картинкой, именем и статусом;
- подгрузка следующей страницы при прокрутке;
- поиск по имени — запрос уходит через 400 мс после того, как перестал печатать;
- состояния загрузки, ошибки (с кнопкой «Повторить») и пустого результата; ошибка подгрузки не сбрасывает уже загруженный список;
- экран персонажа: имя, картинка, статус, вид, пол, происхождение и текущая локация;
- после возврата из деталей список остаётся на том же месте — с тем же поиском и загруженными страницами.

## Стек

Flutter 3.47 / Dart 3, flutter_bloc + bloc_concurrency, Dio, get_it, equatable. Тесты — bloc_test и mocktail.

## Структура

```
lib/
  core/                 DI (get_it), настройка Dio, общая ошибка AppFailure
  features/characters/
    domain/             сущности и интерфейс репозитория
    data/               REST-источник, разбор JSON, реализация репозитория
    presentation/       CharactersBloc, экраны и виджеты
```

Несколько решений, которые стоит пояснить:

- на поиск без результатов API отвечает 404 `{"error": "There is nothing here"}` — считаю это пустым списком, а не ошибкой;
- обработчик поиска работает через `restartable()`, поэтому ответ на устаревший запрос не перезапишет свежий; подгрузка страниц — через `droppable()`, чтобы прокрутка не плодила одинаковые запросы;
- если во время подгрузки поменяли запрос, результат старой подгрузки отбрасывается;
- состояние списка живёт в блоке экрана каталога, а детали открываются поверх через `Navigator.push`, поэтому при возврате ничего не перезагружается;
- после ошибки подгрузки прокрутка не повторяет запрос сама — для этого в конце списка есть кнопка.

## Запуск

```bash
flutter pub get
flutter run              # Android / iOS
flutter run -d chrome    # веб
```

## Тесты

```bash
flutter test
```

Покрыты разбор JSON, источник данных (в том числе 404 → пустой результат), репозиторий (преобразование ошибок Dio), блок (первая страница, подгрузка, конец списка, ошибки, поиск) и экран (состояния, повтор, задержка поиска, переход в детали).
